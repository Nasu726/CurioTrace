Why CurioTrace asks for website access

CurioTrace needs access to normal web pages while a recording session is active so the same session can stay complete as you move between sites and tabs.

  • Granting this permission does not start background monitoring.
  • CurioTrace reads browsing content only after Start and stops while Paused or after Stop.
  • Private/incognito and excluded pages remain outside the intended capture scope.
  • This permission does not authorize sending browsing data to an external AI service.
  • If you decline, the recording test will not start rather than silently creating a partial session.
